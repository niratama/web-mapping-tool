# GridMap Studio (方眼紙マッピングツール)

Webブラウザ上で軽快に動作する、方眼紙ベースのマップ作成・編集ツールです。
サーバーサイドは一切不要で、純粋な HTML5 + CSS3 + Vanilla JavaScript で構築されています。

---

## 🌟 主な機能

### 1. フリースクロール・無限キャンバス
- キャンバス全体のサイズ制限なし。広大なマップを自由に作図可能。
- **パン（画面移動）**: `Space` キー＋ドラッグ、マウス中ボタンドラッグ、または「手のひらツール」。
- **ズーム（拡大・縮小）**: マウスホイール（0.15倍〜5.0倍）、画面右下の拡大/縮小/100%/全体フィットボタン。

### 2. 見た目グリッド と 配置スナップグリッドの分離
- **二層グリッドシステム**:
  - 見た目グリッド（標準 40px）
  - 配置スナップグリッド（標準 1:2 分割 = 20px 単位スナップ）
- グリッド設定モーダルから、マス目ピクセル数や分割比率（1:1, 1:2, 1:3, 1:4）、グリッド線の色、補助線の表示/非表示をいつでも変更可能。

### 3. 床の塗りつぶし & 外周壁の自動生成
- **部屋・床塗りつぶしツール (`F`)**:
  - 見た目グリッド単位でドラッグすると床が塗られ、**その外周境界線（エッジ）が自動的に壁として生成**されます。
  - 隣接するマス目を塗り足すと、自動的に部屋が結合されて外周のみが壁になります。
  - 床には単色カラーだけでなく、テクスチャ（木目フローリング、タイル、石畳、畳、カーペット）を適用可能。
- **厳選カラープリセット & ユーザーカスタム色追加**:
  - 床・壁・家具・開口部の各色指定に、木目・石畳・畳・スレート・白壁等のプリセットを常備。
  - プリセット列末尾の `＋` ボタンで、現在選択中の色をワンクリックでパレットへ登録（`LocalStorage` で永続保存）。
  - 不要になったカスタム色は **右クリックでいつでも削除** 可能。
- **高精度キャンバススポイト**:
  - カラーピッカー横のスポイトボタンで、キャンバス上の床・壁・家具・開口部の色をリアルタイム拡大プレビューしながら直接抽出。ブラウザのOS制限を受けずに確実に動作。

### 4. 交点接続 自由壁ツール (`W`)
- グリッドの交点（配置グリッドの交点）をクリック・ドラッグして結ぶことで、斜め壁や部屋の仕切り壁などを手動で追加できます。

### 5. 消しゴムツール (`E`) と消去対象フィルター
- **消去対象フィルター**: 消しゴム選択時にツールバーおよび左パネルから対象を絞り込み可能：
  - **すべて (All)**: オブジェクト、壁、開口部、床のすべてを消去。
  - **オブジェクトのみ**: 壁や床は一切消さず、**家具やパーツオブジェクトだけを消去**。
  - **壁・開口部のみ**: オブジェクトや床を保護し、**壁とドア・窓だけを修正・消去**。
  - **床のみ**: オブジェクトや壁を保護し、**床セルだけを消去**。

### 6. 開口部（ドア・窓・通路）システム
- 壁のエッジ上にスナップ配置できるドア（片開き戸・両開き戸）、窓、アーチ開口部パーツ。
- 配置時に壁が自動で切り欠かれ、建築図面風の開口部シンボルがレンダリングされます。

### 7. オブジェクト & テキストラベル機能
- 配置グリッド単位のサイズで任意の形状を作成可能：
  - **矩形（幅×高さ）**
  - **セルブロック（4×4マスをクリックして作るL字型・凸凹形状）**
- スタイリング: 単色カラー塗りつぶし、枠線、または画像ファイル（テクスチャ・写真）の貼り付け。
- **テキストラベル**:
  - パレット登録時の初期テキスト設定（例: 「机」「会議室A」など）。
  - マップ配置後、オブジェクトを選択してテキストの書き換え・フォントサイズ・文字色を自由に編集可能。
- パレットからのドラッグ＆ドロップ配置、およびクリック配置に対応。

### 8. パーツライブラリ & Prefab機能
- **パレットのグループ管理**: 基本パーツ、家具、ドア・窓、ダンジョン、カスタムなどのタブで分類。
- **ライブラリ単体保存・読込**: 選択中のグループのパーツ群を「パーツライブラリ（.json）」として個別保存＆読み込み。
- **Prefab（複合パーツ）**: マップ上で複数選択した家具や部屋セットを、1つのパーツとしてパレットに保存・一括再利用可能。

### 9. マウス基本操作 ＋ カスタマイズ可能ショートカット
- **マウス中心**: すべての操作がマウスだけで直感的に行えます。
- **ホットバー（クイックスロット 1〜0）**:
  - 画面下部にスロット 1〜10（キー: `1`〜`0`）を常時表示。
  - パレットのアイテムをスロットにドラッグ（または右クリック）で登録し、数字キーで即座に選択・配置モードへ切り替え。
- **ショートカットキーのカスタマイズ**:
  - 「キー設定」モーダルから好みのキーバインドに変更・永続保存（LocalStorage）。

### 10. 複数選択 & コピペ・一括操作
- **範囲選択（ラバーバンド）**: キャンバスの余白をドラッグして矩形選択枠で複数オブジェクトを一括選択。
- **`Ctrl+C` / `Ctrl+V`**: コピー＆ペースト。
- **`Ctrl+D`**: 即座に複製。
- **一括移動・一括回転 (`R`)・一括削除 (`Delete`)**。

### 11. 画像エクスポート & データ保存
- **PNGエクスポート**: オブジェクトや壁の全体領域（バウンディングボックス）＋余白を自動計算して画像化。グリッド線の有無・背景透過の選択可能。
- **SVGエクスポート**: ベクタ形式（.svg）で高品質に出力。
- **JSON保存 & 読込**: マップの全データを完全保存・復元（画像もBase64で内包するため1ファイルで共有可能）。
- **オートセーブ（自動一時保存）**: 編集ごとにブラウザの `LocalStorage` にバックアップされ、誤ってリロードしても直前の作業状態を復元。

## ⌨️ デフォルト ショートカットキー一覧

| キー | 機能 |
| :--- | :--- |
| `V` | 選択ツール（クリック選択、ドラッグ移動、ラバーバンド複数選択） |
| `F` | 床・壁塗りつぶしツール（見た目マス塗り＋外周壁自動生成） |
| `W` | 壁線ツール（交点接続による自由壁作成） |
| `D` | ドア・窓ツール（壁への開口部配置） |
| `E` | 消しゴムツール（クリックで床・壁・オブジェクト消去） |
| `H` / `Space + ドラッグ` | 手のひらツール（画面移動 / パン） |
| `R` | 選択中アイテムの回転（ドア・窓は開き向きを180°反転） |
| `Delete` / `Backspace` | 選択中アイテム（オブジェクト・壁・ドア/窓）の削除 |
| `Ctrl + Z` | 元に戻す（Undo） |
| `Ctrl + Y` (または `Ctrl+Shift+Z`) | やり直す（Redo） |
| `Ctrl + C` / `Ctrl + V` | コピー ＆ ペースト |
| `Ctrl + D` | 複製（Duplicate） |
| `Ctrl + S` | マップのJSON保存 |
| `G` | 配置スナップ補助線の表示 / 非表示トグル |
| `1` 〜 `0` | ホットバーのクイックスロット 1〜10 のアイテムを即座に選択 |

## 🚀 使い方・起動方法

サーバーサイドアプリケーションは不要です。

1. **直接開く場合**:
   `index.html` をお好みのブラウザ（Google Chrome, Edge, Firefox, Safari等）にドラッグ＆ドロップして開くだけで、オフラインでも全機能が動作します。

2. **ローカルサーバーで開く場合**:
   ```bash
   # Python を使用する場合
   python3 -m http.server 8000
   # ブラウザで http://localhost:8000 を開く
   ```

## 📁 ディレクトリ構成

```
web-mapping-tool/
├── index.html           # メインHTML（UIレイアウト、モーダル、ホットバー）
├── css/
│   └── style.css        # モダンで洗練されたUIスタイルシート
├── js/
│   ├── app.js           # アプリケーション起動・UIイベント調整
│   ├── state.js         # データ状態管理、履歴（Undo/Redo）、オートセーブ
│   ├── grid.js          # グリッド幾何計算、スナップ、無限グリッド描画
│   ├── walls.js         # 外周壁自動生成、自由壁、開口部スナップ
│   ├── objects.js       # オブジェクト当たり判定、形状、変形、テキスト
│   ├── renderer.js      # Canvas 2D描画（床テクスチャ、壁、開口部、プレビュー）
│   ├── palette.js       # パレットUI、新規パーツ作成、ライブラリ管理
│   ├── hotbar.js        # 数字キー1〜0のクイックスロット管理
│   ├── shortcuts.js     # キーバインド監視、カスタマイズ設定
│   └── export.js        # PNG/SVGエクスポート、JSON保存/読込
└── test/
    ├── logic_test.js    # コアロジック単体テスト
    └── dom_integrity_test.js # DOM整合性テスト
```
