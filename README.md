# GridMap Studio (方眼紙マッピングツール)

[![Live Demo](https://img.shields.io/badge/Live_Demo-公開サイトで試す-2563eb?style=flat-square&logo=googlechrome&logoColor=white)](http://nira.poi.jp/web-mapping-tool/)

> 🚀 **オンラインですぐに使える Web版 はこちら**:  
> 👉 **[http://nira.poi.jp/web-mapping-tool/](http://nira.poi.jp/web-mapping-tool/)**

Webブラウザ上で軽快に動作する、方眼紙ベースのマップ作成・編集ツールです。
サーバーサイドは一切不要で、純粋な HTML5 + CSS3 + Vanilla JavaScript で構築されています。

---

## 🌟 主な機能

### 1. フリースクロール・無限キャンバス
- キャンバス全体のサイズ制限なし。広大なマップを自由に作図可能。
- **パン（画面移動）**: `Space` キー＋ドラッグ、マウス中ボタンドラッグ、または「手のひらツール (`H`)」。
- **ズーム（拡大・縮小）**: マウスホイール（0.15倍〜5.0倍）、画面右下の拡大/縮小/100%/全体フィットボタン。

### 2. 見た目グリッド と 配置スナップグリッドの分離
- **二層グリッドシステム**:
  - 見た目グリッド（標準 40px）
  - 配置スナップグリッド（標準 1:2 分割 = 20px 単位スナップ）
- **グリッド設定モーダル**:
  - マス目ピクセル数（10px〜200px）や分割比率（1:1, 1:2, 1:3, 1:4）を自由調整。
  - メイングリッド線の色・配置スナップ補助線の色を個別に設定。
  - スナップ補助線の表示/非表示（`G` キーでもトグル可能）。
  - **床の上にもグリッド線を表示（ON/OFF）**: 有効時は床タイルの上にもグリッド線が綺麗に描画され、建築図面や方眼紙としての位置関係がひと目で把握可能（PNG/SVGエクスポートにも反映）。

### 3. 床の塗りつぶし（3つのモード）& 外周壁の自動生成
- **床・壁塗りツール (`F`)**:
  - **🖌️ ブラシモード**: 見た目グリッド単位でドラッグして1マスずつ直感的に塗り（`Shift` 押下で矩形塗り）。
  - **⬛ 矩形モード**: 対角2点をドラッグして四角い部屋を一発で作成。
  - **🪣 バケツ（塗りつぶし）モード**: クリックした隣接する接続部屋の床色・テクスチャを一括塗り替え。
- **外周壁の自動生成（トグル対応）**:
  - 床を塗ると**その外周境界線（エッジ）が自動的に壁として生成**されます。
  - 隣接するマス目を塗り足すと自動で部屋が結合され、部屋の外周のみが壁になります。
  - 設定により「床塗りと同時に外周壁を自動生成」のチェックを外せば、壁を作らず床だけを塗ることも可能。
- **床の一括色替え**:
  - 「すべての床をこの色に変更」ボタンで、マップ上のすべての床セルを現在の指定色・テクスチャに一括置換。
- **豊富な床・壁テクスチャ**:
  - **高品質リアルテクスチャ**: 木目フローリング、石畳（舗装路）、大理石タイル、ダンジョン敷石、畳などの真上見下ろし（トップダウン）シームレステクスチャを内蔵。
  - **シンプル線画テクスチャ**: 軽量なプロシージャル線画パターン（木目、タイル、石畳、畳、カーペット）も選択可能。
  - **Google Drive クラウドテクスチャ同期**: クラウド上の画像ファイルをワンクリックで床や壁に適用でき、内蔵サンプルの Google Drive への一括登録にも対応。

### 4. 交点接続 自由壁ツール (`W`)
- グリッドの交点（配置グリッドの交点）をクリック・ドラッグして結ぶことで、斜め壁や部屋の仕切り壁などを手動で追加できます。

### 5. 開口部（ドア・窓・通路）システム (`D`)
- 壁のエッジ上にスナップ配置できるドア（片開き戸・両開き戸）、窓、アーチ開口部パーツ。
- 配置時に壁が自動で切り欠かれ、建築図面風の開口部シンボルがレンダリングされます。
- **配置前回転 & 向き反転**:
  - 配置前に `R` キー（またはプロパティボタン）で**開き向き（内開き・外開き）や吊元（左右）を自在に反転・回転**可能。
  - 壁に近づくとターゲット壁がハイライトされ、開口部の配置プレビューと切り欠きがリアルタイム表示されます。

### 6. 消しゴムツール (`E`) と消去対象フィルター
- **消去対象フィルター**: ツールバーおよび設定パネルから消去対象を絞り込み可能：
  - **すべて (All)**: オブジェクト、壁、開口部、床のすべてを消去。
  - **オブジェクトのみ**: 壁や床は一切消さず、**家具やパーツオブジェクトだけを消去**。
  - **壁・開口部のみ**: オブジェクトや床を保護し、**壁とドア・窓だけを修正・消去**。
  - **床のみ**: オブジェクトや壁を保護し、**床セルだけを消去**。

### 7. オブジェクト作成 & 最大8×8マトリクスエディタ
- 配置グリッド単位のサイズで任意の形状を作成・配置可能：
  - **矩形（幅×高さ）**
  - **セルブロック（最大8×8マス）**: 2×2〜8×8マスのインタラクティブグリッドをクリックして、L字型・コの字型・凸凹形状・迷路状のパーツを自在に設計。
- **スタイリング**: 単色塗りつぶし、枠線色・枠線幅、または画像ファイル（PNG/JPG/SVG/WebP）の貼り付け。
- **テキストラベル**: オブジェクト内に文字を表示（フォントサイズ、文字色）。
- **配置前回転**: パレットから選択中、マップに置く前に `R` キーでゴーストを90°ずつ回転可能（テキストも正確に回転追従）。
- **デフォルト値に戻す**: マップ上で編集したオブジェクトを、プロパティパネルからいつでもパレット初期設定値へワンクリック復元。

### 8. パーツライブラリ & パレット管理（編集・複製・削除）
- **UIレイアウトの最適化**:
  - 左サイドバーにパーツパレット（パーツ一覧・ライブラリ管理・新規作成）、右サイドバーにツールプロパティと選択中要素のプロパティを分離。作業中の視認性を大幅に向上。
- **パレットアイテムの編集・複製・削除**:
  - パレット内の各アイテムにホバーすると、鉛筆アイコン（編集）、コピーアイコン（複製）、ゴミ箱アイコン（削除）が表示され、登録済みパーツのカスタマイズが容易。
- **グラフィカルなサムネイル**: パレット一覧上で実際の形状や色がひと目でわかるリアルタイムサムネイルを表示。
- **グループ管理 & ライブラリ保存**:
  - 基本パーツ、家具、ドア・窓、ダンジョン、カスタムなどのグループタブ。
  - 選択中グループのパーツ群を「パーツライブラリ（.json）」として個別エクスポート＆インポート可能。
- **Prefab（複合パーツ）**: マップ上で複数選択した家具や部屋セットを、1つのパーツとしてパレットに保存・一括再利用可能。

### 9. 全面的なカラー管理（厳選プリセット・カスタム色・スポイト）
- **すべてのカラー設定に対応**:
  - 床色、壁色だけでなく、オブジェクト塗りつぶし色、枠線色、文字色、ドア・窓色、グリッド線色、スナップ補助線色のすべてに厳選カラーパレットを完備。
- **カスタム色の追加 & 削除**:
  - プリセット列末尾の `＋` ボタンで、現在選択中の色をワンクリックでお気に入り登録（`LocalStorage` で永続保存）。
  - 不要になったカスタム色は **右クリックでいつでも削除** 可能。
- **高精度キャンバススポイト**:
  - カラーピッカー横のスポイトボタンで、キャンバス上の床・壁・家具・文字・開口部の色をリアルタイム拡大プレビューしながら直接抽出。

### 10. マウス基本操作 ＋ ショートカットキー
- **マウス中心**: すべての操作がマウスだけで直感的に行えます。
- **ホットバー（クイックスロット 1〜0）**:
  - 画面下部にスロット 1〜10（キー: `1`〜`0`）を常時表示。
  - パレットのアイテムをスロットにドラッグ（または右クリック）で登録し、数字キーで即座に選択・配置モードへ切り替え。
- **ESCキーによる即時リセット**:
  - `ESC` キーを押すことで、オブジェクト・壁・開口部の選択状態を解除し、パレットの配置モードをキャンセルして基本の「選択ツール (`V`)」へ即座に復帰。
- **ショートカットキーのカスタマイズ**:
  - 「キー設定」モーダルから好みのキーバインドに変更・永続保存（LocalStorage）。

### 11. 複数選択 & コピペ・一括操作
- **範囲選択（ラバーバンド）**: キャンバスの余白をドラッグして矩形選択枠で複数オブジェクトを一括選択。
- **`Ctrl+C` / `Ctrl+V`**: コピー＆ペースト。
- **`Ctrl+D`**: 即座に複製。
- **一括移動・一括回転 (`R`)・一括削除 (`Delete`)**。

### 12. 画像エクスポート & データ保存
- **PNGエクスポート**: オブジェクトや壁の全体領域（バウンディングボックス）＋余白を自動計算して画像化。グリッド線の有無・床上グリッド線・背景透過の選択可能。
- **SVGエクスポート**: ベクタ形式（.svg）で高品質に出力。
- **JSON保存 & 読込**: マップの全データを完全保存・復元（画像もBase64で内包するため1ファイルで共有可能）。
- **オートセーブ（自動一時保存）**: 編集ごとにブラウザの `LocalStorage` にバックアップされ、誤ってリロードしても直前の作業状態を復元。

### 13. Google Drive クラウド連携
- **完全クライアントサイド（サーバーレス）**: バックエンドサーバーを介さず、ブラウザから Google Drive API を直接呼び出して安全に連携。
- **専用フォルダ自動管理**: Google Drive 直下に `GridMapStudio/` および `Textures/` フォルダを自動作成し、マップファイルやテクスチャ画像を整理。
- **クラウド保存・読込・削除**: ワンクリックで新規保存、既存ファイルへの上書き保存、クラウドからの読込、不要ファイルの削除が可能。
- **テクスチャ画像の同期**: Google Drive 上の画像（PNG/JPG/SVG/WebP）を読み込んで床や壁のテクスチャに直接適用可能。
- **ハイブリッド Client ID**: 公開サイトでは公式 Client ID が自動適用され、ローカル環境でも独自 Client ID をモーダルから簡単に設定可能（詳細は [GOOGLE_DRIVE_SETUP.md](docs/GOOGLE_DRIVE_SETUP.md) 参照）。

### 14. 環境設定のインポート / エクスポート (バックアップ & 復元)
- **ワンクリック完全バックアップ**: グリッド表示設定、キーボードショートカット、お気に入りカスタム色、自作パレットパーツ、ホットバー登録をまとめて 1 つの JSON ファイル（`gridmap_settings_*.json`）にエクスポート。
- **柔軟な選択的インポート**: 読み込み時にプレビューを確認し、復元したい設定項目（グリッド、色、パーツ、キーバインドなど）を個別のチェックボックスで選んで適用可能。
- **PC・ブラウザ間の移行・チーム共有**: 別 PC や別ブラウザへの環境移行、ブラウザのキャッシュクリア対策、チーム内での統一設定配布に最適。
- **安心の初期化機能**: 必要に応じていつでも工場出荷時のデフォルト設定へワンクリックでリセット可能（作図中のマップデータは保持されます）。

## 🎨 テクスチャの使い方・描き方ガイド

GridMap Studio では、**「床面（フロア）へのシームレステクスチャ描画」** と **「オブジェクト（家具やダンジョンパーツ）へのテクスチャ画像適用」** の両方に対応しています。

### 1. 床（フロア）へのテクスチャの塗り方

1. **床・壁ツールを選択**:
   - ツールバーの「床・壁」アイコンをクリックするか、キーボードの **`F`** キーを押します。
2. **右パネルでテクスチャを選択**:
   - 右サイドバーの「ツール設定」内にある **「床テクスチャ」** プルダウンから好みのテクスチャを選びます:
     - **高品質リアルテクスチャ**: 木目フローリング、舗装石畳、大理石タイル、ダンジョン敷石、畳
     - **シンプル線画パターン**: 木目（線画）、タイル、石畳、畳、カーペット
     - **なし**: 単色カラー塗りつぶし
3. **塗りモードを選んで描画**:
   - **🖌️ ブラシモード**: マウスドラッグで 1 マスずつ直感的に塗ります。
   - **⬛ 矩形モード**: 対角 2 点をドラッグして、四角い部屋を一発で塗りつぶします（ブラシモード中でも `Shift` キーを押しながらドラッグすると矩形塗りになります）。
   - **🪣 バケツ（塗りつぶし）モード**: 部屋の床をクリックすると、接続された同色の部屋領域全体を一括で現在のテクスチャに塗り替えます。
4. **部屋全体で模様が自然に繋がるシームレス仕様**:
   - ワールド座標基準のタイリング方式を採用しているため、1マスごとにテクスチャが途切れることなく、広い部屋でも木目や石畳、畳（実物比率の1×2対比）が美しく連続して描画されます。
5. **一括テクスチャ変更**:
   - 右パネルの **「🗺️ すべての床をこの色に変更」** ボタンをクリックすると、マップ上の全フロアセルを指定テクスチャへ一括変換できます。

---

### 2. オブジェクト（家具・備品・パーツ）へのテクスチャ適用

#### 方法 A: パレットからプリセットパーツを配置する
1. 左サイドバーのパーツパレット上部にあるタブを切り替えます:
   - **「家具・備品」タブ**: 高級木製テーブル、大理石カウンター、高級装飾ラグ（ペルシャ絨毯）など
   - **「ダンジョン」タブ**: 豪華な装飾宝箱、古代ルーン祭壇、召喚の魔方陣など
2. 配置したいパーツをクリック（またはキャンバスへドラッグ＆ドロップ）します。
3. 配置前に **`R`** キーを押すと、90度ずつ回転できます。
4. キャンバス上の置きたい場所をクリックして配置します。

#### 方法 B: 既存のオブジェクトに手持ちの画像を適用する
1. キャンバス上の任意のオブジェクトをクリックして選択します（青い枠線が表示されます）。
2. 右サイドバーの「オブジェクトプロパティ」にスクロールします。
3. **「テクスチャ画像」** 項目の **「ファイルを選択」** ボタンをクリックします。
4. お手持ちの画像ファイル（PNG / JPG / WebP / SVG）を選択すると、即座にオブジェクトの天板・表面にテクスチャ画像が適用されます。
5. サイズ（幅・高さ）の変更や、`R` キーによる回転にも完全に追従します。

#### 方法 C: 新規パーツとしてテクスチャオブジェクトを作成・保存する
1. 左サイドバーのパーツパレット下部にある **「＋ 新規パーツ作成」** ボタンをクリックします。
2. モーダルが開いたら、パーツ名（例: 「特注絨毯」など）とグループ（家具、ダンジョン、カスタム等）を設定します。
3. **塗りつぶし種別** で **「画像」** にチェックを入れます。
4. **「画像を選択」** ボタンから使いたいテクスチャ画像をアップロードします（プレビューが表示されます）。
5. サイズ（幅・高さ）を入力し、**「パレットに追加」** をクリックします。
6. パレットに登録され、以降は何度でもスタンプ感覚でキャンバスへ配置できるようになります。

---

### 3. Google Drive とのテクスチャ連携

1. 画面上部ヘッダーの **「クラウド」** ボタンをクリックします。
2. Google でログイン後、**「📦 サンプル登録」** ボタンを押すと、内蔵の高解像度テクスチャ画像（木目、石畳、大理石、ダンジョン石、畳、装飾ラグ、魔法陣、宝箱、祭壇）が Google Drive の専用フォルダ（`GridMapStudio/Textures/`）へ自動登録されます。
3. クラウド上の画像テクスチャをクリックするだけで、マップの床や壁へワンクリックで直接適用できます。

## 🚀 使い方・起動方法

サーバーサイドアプリケーションは不要です。

1. **直接開く場合**:
   `index.html` をお好みのブラウザ（Google Chrome, Edge, Firefox, Safari等）にドラッグ＆ドロップして開くだけで、オフラインでも全機能が動作します。

2. **ローカルサーバーで開く場合**:
   Python でも Node.js でも、外部パッケージのインストール不要で手軽に起動できます。

   ```bash
   # Node.js を使用する場合 (おすすめ)
   npm run serve
   # または npm start (http://localhost:8000 で起動)

   # Python を使用する場合
   python3 -m http.server 8000
   # ブラウザで http://localhost:8000 を開く
   ```
