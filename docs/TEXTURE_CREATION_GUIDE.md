# GridMap Studio テクスチャ制作・導入ガイド (Texture Creation Guide)

本ドキュメントは、**GridMap Studio (方眼紙マッピングツール)** において自作のテクスチャ画像（床パターン・家具・装飾・ダンジョンパーツ等）を作成・インポートするための仕様およびベストプラクティスをまとめたガイドです。

---

## 1. テクスチャの 2 つの用途

GridMap Studio では、テクスチャを以下の 2 つの異なる用途で利用できます。

| 用途 | 対象 | 描画方式 | 推奨形式 |
| :--- | :--- | :--- | :--- |
| **床（フロア）テクスチャ** | マップの床面全体 | **ワールド座標系シームレスタイリング**<br>部屋が何マスあっても絵柄が途切れず連続 | JPG / PNG (不透明または半透明パターン) |
| **オブジェクトテクスチャ** | 机、絨毯、宝箱、魔法陣、トークン等 | **単体スケーリング & 回転**<br>オブジェクトの矩形領域にフィット描画 | **透過PNG (32bit RGBA)** / WebP / SVG |

---

## 2. 床（フロア）テクスチャの作り方

### 2.1 シームレス（上下左右のつなぎ目なし）タイリング
床テクスチャは、部屋のマス目がいくつ繋がっても境界線が見えない **「シームレステクスチャ（Seamless Tile）」** を使用します。
Photoshop の「スクロール（オフセット）」フィルターや、GIMP、クリップスタジオ等のシームレスパターン作成機能を用いて、上下・左右の端がピクセル単位で滑らかに繋がるように制作してください。

### 2.2 解像度とグリッド比率
- **標準解像度**: `128×128px` 〜 `512×512px`（正方形）
  - 当ツールはブラウザ上で軽量に動作するため、1ファイルあたり `100KB〜300KB` 前後が最適です。
- **グリッドスケール**:
  - 見た目グリッドの 1 マス（標準 `40px`）に対して、テクスチャが何マス周期で繰り返されるかを想定して制作します。
  - 例: 石畳や木目は `2×2マス（80px相当）` または `4×4マス（160px相当）` の周期。
- **特殊比率（畳など）**:
  - 和室の畳のように「1枚あたり 1:2 の縦横比」を持つテクスチャは、4枚を風車状（あるいは四畳半・本羽重ね）に並べた `4×4マス周期` の正方形シームレス画像として制作することで、実物通りの美しい敷き詰めが表現されます。

### 2.3 床色とのブレンド（透過PNG床テクスチャ）
- 床セルに透過PNGテクスチャを適用すると、指定した「床色（`floorColor`）」の上にテクスチャの線画・陰影が重なって合成されます。
- 例: グレースケールの線画タイルテクスチャを用意しておけば、床色を「緑」「青」「砂色」に変えるだけで、同じテクスチャから無数のカラーバリエーションを生成できます。

## 3. オブジェクトテクスチャの作り方

### 3.1 32bit RGBA 透過PNG（透明背景）の活用
オブジェクトパーツ（円形絨毯、魔法陣、宝箱、祭壇、焚き火、キャラクターコマ等）には、**背景が完全に透明な 32bit RGBA PNG** が最適です。
- 透明部分は背後の床テクスチャやグリッド線がそのまま透けて見えます。
- 半透明のシャドウ（影）や発光エフェクト（グロー）を含む PNG も、Canvas 2D のアルファブレンドにより美麗にレンダリングされます。

### 3.2 完全フチなし描画（四角い枠線を消す）
円形や不定形のパーツを配置する際は、四角い矩形枠線を消して自然に配置できます:
1. オブジェクト選択時のプロパティパネルで、**「枠線幅」を `なし (0px)`** に設定します。
2. または「枠線色」を `transparent` に指定します。
3. これにより、キャンバス描画時および **PNG / SVG 画像エクスポート時にも四角い外枠が一切出力されず、美しいフチなし配置** となります。

### 3.3 推奨解像度
配置グリッド（標準 `20px` 単位）または見た目グリッド（標準 `40px` 単位）の整数倍で制作すると、ドットの潰れやぼやけが最小限に抑えられます。
- 1×1 マス用パーツ（宝箱、オフィスチェア、篝火など）: `80×80px` (2x 解像度)
- 2×2 マス用パーツ（丸テーブル、祭壇、装飾ラグなど）: `160×160px`
- 4×4 マス用パーツ（大型魔法陣、巨大樹など）: `320×320px`

## 4. テクスチャのインポート & 適用方法

### 方法 1: 既存オブジェクトへの画像貼り付け
1. キャンバス上の任意のオブジェクトをクリックして選択します。
2. 右サイドバーの「オブジェクトプロパティ」で **「画像変更」**（ファイルを選択）をクリックします。
3. ローカルの画像（PNG / JPG / WebP / SVG）を選ぶと、即座に適用されます。

### 方法 2: 新規パーツとしてパレットへ登録
1. 左サイドバー下部の **「＋ 新規パーツ作成」** ボタンをクリックします。
2. パーツ名とグループ（家具、ダンジョン、カスタム等）を入力します。
3. **塗りつぶし種別** で **「画像」** を選択し、**「画像を選択」** から画像をアップロードします。
4. **枠線幅**（フチなしにしたい場合は `0px`）やサイズを設定し、**「パレットに追加」** をクリックします。
5. 以降はパレットから何度でもワンクリックで配置できます。

### 方法 3: Google Drive 経由でのクラウド同期
1. ヘッダーの **「クラウド」** ボタンから Google アカウントで接続します。
2. Google Drive 直下の `GridMapStudio/Textures/` フォルダへお好みのテクスチャ画像（PNG/JPG等）を保存しておくと、ツール内のクラウドマネージャーにサムネイル一覧が自動表示されます。
3. サムネイルをクリックするだけで、床や選択中オブジェクトへ瞬時に適用されます。

---

## 5. ポータビリティと共有（リンク切れ防止）

- マップを **JSON 保存（`Ctrl + S`）** する際、外部から読み込んだ画像データは自動的に **Base64 DataURL 形式** として JSON ファイル内に完全内包されます。
- そのため、画像ファイルを別個に添付・送付する必要がなく、**単一の `.json` ファイルを誰かに渡すだけで、自作テクスチャを含めたマップ全体が 100% 完全に復元** されます。
